**An invalid option names the function you called**: an option that an indicator hands on to another function raised an error naming the inner one, for example `apo(mamode="ema", adjust="yes")` named `ema()`, `atr(mamode="linreg", slope="yes")` named `linreg()`, `macdfix(xa="x")` named `macd()` and `rsi(xserie="yes", signal_indicators=True)` named `_add_series_signals()`. The error now names the indicator you called, and `inertia(rvi_length=1)` and `squeeze(bb_length=1)` name the parameter you passed; valid calls are unchanged.

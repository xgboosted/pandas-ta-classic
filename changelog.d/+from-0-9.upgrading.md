**Upgrading from 0.9.0**: it needs `pandas>=3.1.0`, `numpy>=2.4.6`; `custom.load_indicator_module()` is gone; a custom indicator may not reuse a package name. An unknown keyword raises `TypeError` (`strategy()` passes only accepted ones); `fast` above `slow` raises; flags take only True, False, None; `chop`, `hvol` and `stderr` need `length > 1`. Column names carry each non-default parameter that changes values. Price-relative indicators read NaN, and warn, at prices <= 0. Results change for `rsi`/`qqe` on a flat start, `kama`, `psar`, `fisher`, `msw` and `sharpe_ratio(use_cagr=True)` with a rate; `cdl_inside` (`CDL_INSIDE`) reads 0 on a missing bar; `fosc`, the uncentered `dpo`, `pvt`, `nvi` and `pvi` equal TA-Lib (`nvi`/`pvi` rescale); seven indicators honour their MA options; `fillna` and `offset` change on some option paths. `talib=True` runs natively for a parameter TA-Lib cannot express; `mamode` accepts the same values on both. `stc`'s `ma1`, `ma2` and `osc` need close's index.

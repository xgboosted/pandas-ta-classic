**`custom.import_dir()` bound part of a directory when one file was refused**: an `ImportError` from a later file left the earlier modules bound to `pandas_ta_classic`, `AnalysisIndicators` and `Category`, and the refused file's directory on `sys.path`. It now loads every file first and binds them only when none was refused; otherwise it puts back the `sys.path` entries it added and the indicator modules it put into `sys.modules`, and an indicator bound by an earlier call keeps its old code. A name defined in two categories now binds neither file (the first one used to stay bound).

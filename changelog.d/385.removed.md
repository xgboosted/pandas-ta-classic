**BREAKING — `psar()` has no `talib` parameter**: TA-Lib's `SAR` returns the stop alone, so `psar(talib=True)` filled `PSARaf` with NaN on every bar and `PSARr` with 0.0, which hid 521 reversals on SPY_D. The native stop equals `SAR` bar for bar, so `psar(talib=...)` now raises `TypeError`; drop the argument.

**BREAKING — `sharpe_ratio(use_cagr=True)` subtracts `benchmark_rate`**: it returned `cagr / volatility` and never read the rate, so every `benchmark_rate` gave the rate-0 value; it now returns `(cagr - benchmark_rate) / volatility`, as its docstring says. Calls with `use_cagr=True` and a non-zero `benchmark_rate` return a different value.

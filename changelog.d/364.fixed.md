**BREAKING — a custom indicator may not reuse a name the package already has**: `custom.import_dir()` raises `ImportError` and `custom.bind()` raises `ValueError` for a built-in indicator name such as `rsi`, or another name of `pandas_ta_classic` or `df.ta` such as `Category`. Such a file replaced the built-in only in part (`stochrsi` kept the original), and `Category.py` broke `import_dir()`; rename the file and its two functions.

**BREAKING — `psar(af=...)` is now the acceleration step, `af0` the start value**: `af` was never read — it only supplied `af0`'s default, and the loop used `af0` as both the start and the step, so a separate step could not be set. `af` is the step and `af0` the start value; the default call is unchanged and still matches TA-Lib `SAR`, and the column name now carries `af` when it is non-default.

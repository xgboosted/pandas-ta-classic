**BREAKING — the `is_percent()` helper is removed**: it returned `False` for anything it could not use instead of raising, which invited the silent-default guard, and nothing called it. `ta.is_percent` and `pandas_ta_classic.utils.is_percent` now raise `AttributeError` naming the replacement — write `0 <= x <= 100` directly, or validate with `_number(x, default, name, ge=0, le=100)`.

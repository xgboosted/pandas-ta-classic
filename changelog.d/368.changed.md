**BREAKING — a parameter that changes the values names its columns when it is not at its default**: two such calls no longer share a column name and overwrite each other on append. The value is added as `_<name><value>`: `zscore(close, ddof=0)` is `ZS_30_ddof0`, `dpo(close, centered=False)` is `DPO_20_centered0`, `bbands(close, ddof=1)` gives `BBL_5_2.0_ddof1`. Calls with default values keep their names; `scalar`, `drift`, `asint` and `asbool` stay out of names.
